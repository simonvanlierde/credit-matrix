# JATS 1.3 Archiving DTD

Vendored copy of the JATS Journal Archiving and Interchange DTD, version 1.3, with MathML 3.
`scripts/validate-jats.sh` validates the JATS export against it.

- Source: https://public.nlm.nih.gov/projects/jats/archiving/1.3/JATS-Archiving-1-3-MathML3-DTD.zip
  (linked from https://jats.nlm.nih.gov/archiving/1.3/dtd.html, published by the US National Library of Medicine)
- Version: JATS Archiving 1.3, public id `-//NLM//DTD JATS (Z39.96) Journal Archiving and Interchange DTD with MathML3 v1.3 20210610//EN`
- SHA-256 of the zip: `0c646d2eeb5fe41d8093143e6684550267d6c82e97d88bbdaea5ec2299f0bc15`

The files are unmodified. To update, unpack a newer zip over this folder and change this file.
